# EXP-002: 学習方策（Reflex / Learner）は固定方策（Forager）の個体数帯域に届くか（健全性チェック、事前登録）

- 仕様の登録日: 2026-10-17（実行前にこの文書だけをコミットする。結果は実行後に「結果」節へ追記し、仕様の節は書き換えない）
- カーネル: `simulation-core` 0.1.0（ADR-0013 3-7 適用後、Forager のゴールデン `0x658ee873d1866501`）。実行に使うバイナリのコミットは結果節に記す
- 機種: Apple M1（8 コア、16 GB）, rustc 1.99.1, release build
- 種別: **健全性チェック**（ADR-0013 D9、完了条件 3）。研究仮説 H1〜H5 の検証ではない。Forager は設計者が書いた方策、Reflex / Learner も設計者が置いた特徴・状態・報酬の上で動くので、ここで何が出ても創発の証拠にはならない

## 問い

ADR-0013 D9: **学習する方策は、設計者が書いた Forager の個体数帯域に届くか。** 学習が物理の中で「効く」こと（学習者が生き残り、帯域に収束し、Q 表や重みが白紙から動く）を 10 シードで確認する。

仮説表（docs/research/HYPOTHESES.md）との関係: H1〜H5 のどれも直接は検証しない。H1（所有権相当の規範）と Phase 4 の前提「学習者が生き残り、社会行動（移転・加害・発信）が台帳に載る」を満たすかの準備計測であり、RISKS.md R6（加害の退化均衡、報酬ハッキング）の最初の計測でもある。

## 事前に決める指標

すべて `<腕>_summary.csv`（シードごと 1 行）から読む。「窓」は後半 50% の 10,000 tick。「個体·tick」は窓の各 tick の開始時の生存数の総和（= 決定の総数）。

| # | 指標 | 列 | 定義 |
|---|---|---|---|
| M1 | 絶滅 | `extinct_at` | 生存数が 0 になった最初の tick（なければ `-`）。腕ごとに絶滅したシード数 |
| M2 | 帯域 | `win_mean` / `win_min` / `win_max` / `win_max_over_min` | 窓の生存数の平均・最小・最大・最大/最小。シード間の平均・標準偏差（母集団）・CV |
| M3 | 摂取量/体 | `win_consumed_per_agent_tick` | 窓で消費された食料単位 / 個体·tick（1 単位 = 4,000 ミリエネルギー） |
| M4 | 社会行動の件数 | `win_transfers_per_tick` / `win_harms_per_tick` / `win_signals_per_tick` / `win_proposals_per_tick` / `win_acceptances_per_tick` / `win_rejections_per_tick` | 窓で**成立した**移転・加害・発信（Say）・届いた提案・受諾・拒否の件数 / tick（台帳と同じ定義。失敗した試行は入らない） |
| M5 | 死因構成 | `win_deaths_starvation` / `win_deaths_old_age` / `win_deaths_violence` | 窓の死亡数（原因別）と、その比 |
| M6 | 行動構成 | `win_act_move` … `win_act_signal`（8 列） | 窓の決定のうち各種類が占める割合（成功・失敗を問わない。8 列の和 = 1） |
| M7 | Learner の表 | `q_abs_mean` / `q_delta_window` / `<腕>_qpolicy.csv` | 終了時の生存学習者の Q の \|値\| の平均（報酬単位 = 100 ミリエネルギー、固定小数点 16 を割った値）。窓の始め（tick 10,000 の開始時）と終わり（tick 20,000）の**集団平均 Q 表**の差の \|値\| の平均（同単位）。行ごとに「終了時の生存学習者のうち各種類を貪欲に選ぶ個体数」（同点は `tie`） |
| M8 | Reflex の表 | `reflex_weight_drift` / `hunger_permille_mean` | 終了時の生存個体の \|w − w₀\| の平均（w₀ = Forager 等価の初期重み、1.0 = 1024 単位）。`hunger_permille` の平均（突然変異が動かす唯一のスカラー） |
| M9 | 実行時間 | `ticks_per_s`、`RUN.log` の壁時計時間 | シードごとの tick/s（`World::step` 以外も含む）と腕ごとの合計時間 |

探索の床（Learner の判定に使う定数）: ε = 50‰ の探索は 8 種類を一様に選ぶので、どの種類も決定の **0.625%**（= 0.05 / 8）は探索で選ばれる。Transfer / Harm は隣接個体がいなければ Rest に化ける（アクチュエータ、3-6）ので、成立件数はこれ以下になる。「床の 2 倍」= 決定割合 **0.0125** を「貪欲には選ばれていない」の目安にする。

## 既知の限界（事前）

- **単一設定**。既定世界 1 条件、ε 1 値、突然変異幅 1 値、グリッド 1 サイズ。パラメータ格子は扱わない（EXP-001 と同じ限界）。
- **報酬は自己のエネルギーだけ**（ADR-0013 D6）。移転は損なので分かち合いは出なくて当然、出ないことは失敗ではない（Phase 4 の制度が「割に合う」条件を作る）。死に終端の負の報酬はない（D6）ので、学習者は「死を避ける」ことを直接は学ばず、餓死は −5 の連続と Consume の不発としてしか学ばれない。
- **Signal は無料**（`signal_cost` 0）で Rest と報酬で区別がつかない。発信件数は通信の学習の証拠にならない（P5f）。記号の意味も進化・学習しない（3-6: 聞いた記号の反復）。
- **交渉（Propose / Accept / Reject）は Reflex / Learner の行動集合にない**（8 種類、Signal = Say）。F / X / L の腕で `win_proposals_per_tick` 等が 0 なのは構造上の帰結であり、Random だけがこれらを出す。
- **個体数は適応度ではない**。帯域が高いのは 1 個体あたりの消費が少ない（休む、歩かない）結果でもあり得るので、M3（摂取量/体）と M6（行動構成）と合わせて読む。Forager は設計者の参照であって最適解ではない。
- **20,000 tick は進化には短い**（`max_age` の 6.7 倍）。X1-50k で 2.5 倍にするが、それでも収束の保証はない。
- **Violence 死の由来**。Learner の加害は探索（ε）由来が主と予測するが、カーネルは加害が探索か貪欲かを記録しないので、`win_act_harm` と床の比較で間接に判定する。
- **統計**。10 シードの記述統計（平均・sd・CV・対の勝敗数）のみ。信頼区間・検定は出さない。
- 実行時間は `cz sweep` の総時間で、`World::step` 以外（系列の書き出し、表の統計）を含む。
