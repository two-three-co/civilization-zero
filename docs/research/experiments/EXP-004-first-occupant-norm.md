## 問い

H1（HYPOTHESES.md）: 「所有権を事前定義しなくても、競合・記憶・通信・制裁から所有権相当の規範が成立する条件がある」。主要指標は「先占者以外の採取」率とそれに続く制裁の条件付き確率、両者の時間的低下と持続。帰無モデルはランダム方策 / 通信なし / 記憶なし / 制裁不能。

Phase 4 で答えられるのはその最初の半分、「ルールが世界の中の社会的事実として存在し、個体がそれを守り・破り・罰することができ、その効果を事前登録した指標で測れる」か（ADR-0014 の文脈）である。本実験の問い:

1. **学習者の侵害率は、制度を担う個体と規則のある社会で下がるか。** 主腕 LE（Learner 128 行 90% + Enforcer 10%、規則 R）と、同じ seed の LE0（同じ構成、規則なし）の、後半の窓の学習者の侵害率 E_L の対の差。
2. **学習者だけで制裁は出るか。** L1（Learner のみ + R）で制裁の条件付き確率 S′ が探索の床を超えるか（予測: 超えない。制裁に報酬の利得がない）。
3. **何が効いているか（帰無モデル）。** 制裁できない規則（N-nosanction）、規範情報を見ない学習者（N-blind）、通信なし（N-nocomm）、記憶なし（N-nomem）、ランダム方策（N-rand）で、LE の差がどこまで残るか。
4. **制度のコスト。** LE の個体数・死因・摂取は LE0 からどう動くか。
5. **（副次、探索的）制裁が「痛い」と報酬が言えば何が変わるか。** 体力項 `learner_health_weight` 2 の世界（W0 / W1）で、規則の効果の大きさと死因が変わるか。H1 の判定には使わない。

## 分析窓と指標

系列（`<腕>_series.csv`、100 tick ごと）の行 t は区間 (t − 100, t] の計数を持つ。区間 (a, b] の値は **a < t ≤ b の行を合算**して比にする（率の平均ではなく合算比。採集の少ない窓で率が暴れないため）。

- **窓**: tick 2,000〜20,000 を 100 tick の窓 w_k = (2,000 + 100k, 2,100 + 100k]（k = 0〜179）に切る。**序盤** = (2,000, 4,000]、**後半** = (10,000, 20,000]（= `cz sweep` の `--window 50` の窓: summary の `win_*` 列と同じ区間）、**末尾** = (15,000, 20,000]。tick 0〜2,000 は白紙の表の谷（EXP-003: 128 行の谷は tick 200、回復は tick 1,000 まで）として分析に使わない（ただし記述する）。
- N-rand だけは絶滅までの「生涯」を 10 tick ごとの行で読み、生涯の前半 / 後半（絶滅 tick の半分で分ける）を窓にする。

| # | 指標 | 定義（系列の列） | 読む腕 |
|---|---|---|---|
| **M1** | 絶滅 | `extinct_at`（summary）。腕ごとの絶滅シード数と tick | 全腕 |
| **M2** | **学習者の侵害率 E_L(窓)** | Σ `encroachments_learner` / Σ `gathers_learner`（先占者以外の採取 / 成功した採集、ADR-0014 D3 の操作的定義）。**主指標は後半の E_L**。N-rand は `_random` の列で E_R | 全腕 |
| **M3** | 制裁の条件付き確率 | **S(窓)** = Σ `episodes_sanctioned` / Σ `episodes_closed`（エピソード単位）、**S′(窓)** = Σ `sanctions` / Σ `violations`（件数単位。複数の Enforcer が同じ違反者を 1 回ずつ殴るので 1 を超えうる）。方策別: **S′_E** = Σ `sanctions_enforcer` / Σ `violations`、**S′_L** = Σ `sanctions_learner` / Σ `violations` | 規則のある腕 |

## 統計（事前に固定）

- 腕どうしの対比はすべて**同じ seed の対の差** d_i = x_i(腕 A) − x_i(腕 B)。報告するのは: 対の平均、**95% ブートストラップ信頼区間**（対の差を 10,000 回復元抽出した平均の 2.5 / 97.5 パーセンタイル。乱数は `random.Random(20261018)`）、**効果量 d_z** = 平均 / 差の標本標準偏差（ddof 1）、比 = 平均(A) / 平均(B)、予測の向きに差が出たシード数。p 値だけの報告はしない（HYPOTHESES の規則）。
- 主対比（LE − LE0、LE0 − L0、LE − L0）は **30 シード**。帰無モデルと W は 10 シードで、LE / LE0 との対は seed 0〜9 で取る（CI は広い: 10 シードの対比は帰無モデルの**検査**であって H1 の主張ではない）。
- **最小関心効果（SESOI）**: E_L の対の差 **0.01**（絶対値。規則なしの E₀ ≈ 0.08（EXP-003 の 128 行）の 1/8）。CI が 0 を含まず、かつ平均の絶対値 ≥ 0.01 のとき「下がった / 上がった」と書く。CI が [−0.01, +0.01] と重なる差は「SESOI 未満」。
- 絶滅したシード（M1）は対から除く（除いた数を報告する）。LE / LE0 の対が **3 対以上**失われたら H1 の判定は「この設計では読めない（制度のコストが支配）」と記録し、判定文を書かない。
- 単一シードの値は事例としてのみ扱う。

## 主張の書き方（H1 の判定文）

結果節には次の形の文だけを書く: 「**条件 LE で学習者の侵害率（後半の窓）が、同じ seed の LE0 に比べ X 下がった（30 シード、対の平均 −X、95% CI [a, b]、d_z = …、比 …）。N-nosanction では下がらなかった（LE0 と同一）。**」H1 の判定はこの文の成否（P1a と P3）: P1a が外れれば「この設定では先占規範の制裁は学習者の侵害率を下げなかった」と記録し、H1 は未決のまま。

判定文の後に、機構の読みを必ず付ける: 体力項 0 の世界では制裁は学習者の報酬に現れない（EXP-003 / ADR-0014 の前提条件 2）ので、LE の低下は (a) 制裁による侵害者の除去（加害死）、(b) 継承される Q 表への選択、(c) Enforcer が先占者のいるセルを避ける語彙、の合成であり、**学習者が規範を学んだ証拠ではない**。P1b / P1c / P4 / P8 がどれに重みがあるかを示す。「創発」「世界初」「所有権が生まれた」は書かない。

## 既知の限界（事前）

- **Enforcer は設計者の知識**（ADR-0014 D7、R1）。LE で侵害が減っても「従わせる個体を置けば従う」以上ではない。学習方策は立法しない。規則は布告で与え、発明は問うていない。
- **体力項 0 では制裁が学習者の報酬に入らない**（前提条件 2）。学習者が規範に「従うことを学ぶ」経路は本実験には無く、ある差はすべて除去・選択・Enforcer の行動の帰結。W1 / W0 はその限界を探索的に見るだけで、体力項 2 は Learner の目的を変える（EXP-003: Rest が倍増）。
- **構成の維持は実験者の介入**: Enforcer の割合は出生時の割当で 10% に固定され、Enforcer の子として生まれる Learner は白紙の表を持つ（スモーク: 0.2 件/tick ≈ 出生の 10%）。L0 / L1 にはこの流入がない。LE0 − L0 の差には Enforcer の存在とこの流入の両方が入る。
- **N-nosanction は LE0 と物理が同一**（P3）、**N-nocomm は LE とほぼ同一**。帰無モデル 4 本のうち 2 本は設計の帰結を記録するだけで（係争は公知 = R12、v1 の制裁は通信を使わない）、「通信がなくても制度が成り立つ」証拠にはならない。
- **布告が tick 0** なので、白紙の表の谷に制裁が重なり LE の谷は深い（スモーク: tick 400 に 84〜133 体）。絶滅の扱いは「統計」のとおり。tick 2,000 に布告する設計（谷の後）は比較の窓の都合で採らなかった（D11）。
- **侵害の操作的定義は到着順**（D3）で、家族は共同の先占者。密集では誰もが侵害者になりうる。E_L は「所有」の何かを測っていない。
- **S′ は 1 を超えうる**（複数の Enforcer が同じ違反者を 1 回ずつ殴る）。S はエピソード単位で天井が近い。
- **学習者の「制裁」は語彙の帰結**: Harm のアクチュエータが係争中の隣人を先に狙う（D6）ので、探索の Harm が制裁として数えられる。N-blind がこれを切り分ける。
- **10 シードの帰無モデルの CI は広い**。10 シードの対比は検査。
- **スモークを見てから数値を書いた項目がある**（上の「判定規則と予測」の冒頭）。登録シードはスモークと重ならない。
- 窓の率は合算比で、窓の途中の分布（侵害者の個体差）は見ない。採集・侵害は方策別に数えるが死因・摂取は方策別に無い（Learner の加害死 ≠ 全体の加害死。制度世界では Enforcer も殴られうる）。
- 実行時間は `cz sweep` の総時間で参考値。

### H1 の判定文

**条件 LE で学習者の侵害率（後半の窓、tick 10,001〜20,000）が、同じ seed の LE0 に比べ 0.0669 下がった（30 シード、対の平均 −0.0669、95% ブートストラップ CI [−0.0684, −0.0654]、d_z = −15.4、比 0.164 = LE 0.0131 / LE0 0.0800、30/30 シードで低下）。N-nosanction では下がらなかった（LE0 と物理が同一: E_L 0.0815 = 0.0815）。**

機構の読み（判定文の一部として必ず付ける）: 体力項 0 の世界では制裁は学習者の報酬に現れない（EXP-003、ADR-0014 の前提条件 2）。LE の低下は、(a) 制裁（加害 −20 体力）による侵害者の**除去** — 加害死が死因の 13.4% から 57.2% に、Learner の個体数が 1,541 から 1,085 に（−30%）、低下は布告直後の序盤の窓で既に 0.096 → 0.014 で現れ以後増えない（後半/序盤 0.94）— と、(b) Enforcer が先占者のいるセルを採らない語彙、(c) 学習者自身の Harm が係争中の隣人を先に狙う語彙（LE の学習者の加害の 33% が制裁として当たる。盲目の N-blind では 3.8%）の合成であり、**学習者が規範を学んだ証拠ではない**: 制裁の痛みを報酬に入れた W1 は LE と同じ値になり（E_L 0.0141 vs 0.0127、加害死 0.60 vs 0.57）、規範情報を見ない N-blind も同じだけ下がる（0.0174。LE との差 +0.0048 は学習者の制裁が消えた分）。したがって H1 の文は成立するが、それが示すのは「制裁を担う個体と制裁の語彙を置けば、侵害する学習者が殺されて侵害率が下がる」であって、「所有権相当の規範が成立した」ではない。

### 読み（事後の解釈。事前登録の判定ではない）

1. **低下は除去で、学習ではない。** 上の判定文の機構。LE では学習者の加害は 1 体・1 tick あたり 0.00374（L0 0.00258）で、Enforcer 4.62 件/tick + 学習者 1.36 件/tick の制裁が違反 1.85 件/tick に対して S′ 3.25（1 件の違反に 3 体以上が答える）。制裁を受けた侵害者は体力 100 を 5 発で失う。摂取/体·tick は LE の方が高い（0.1755 vs 0.1634）: 個体が減って 1 体あたりの食料が増えた。
2. **学習者だけでも規則は侵害率を下げる（P2c の反証）が、同じ機構。** L1 の加害は 3.96 件/tick で L0（4.20）と同じ予算なのに、その 65% が係争中の隣人に当たり（S′ 0.43）、加害死の割合は 12.9% → 27.9%、Learner は 1,572 → 1,045（−34%）、E_L は 0.074 → 0.047。谷は 53〜88 体（L0 154〜278）と深く、1,000 体に戻るのは 10 シード中 6 で tick 1,300〜8,300、E_L は序盤 0.029 → 末尾 0.050 と密度の回復とともに上がる（E は共在の率で、密度に依る）。**P2a / P2b の反証の中身**: 1 体あたりの Harm の決定は規範ビットが見える腕（L1 0.00379、LE 0.00374、W1 0.00391）で見えない腕（L0 0.00258、LE0 0.00266、N-blind 0.00287）の約 1.45 倍。行 64〜127（係争者が隣接）で Harm が貪欲多数派になった行は全シードで ≤ 3 行、Harm を貪欲に選ぶ学習者の割合も行 64〜127（0.0034〜0.0038）が行 0〜63（0.0036〜0.0051）より高くはない。代わりに行 64〜127 は**最上位が同点の学習者が 71〜76%**（行 0〜63 は 57%）で、訪問も LE で 1/8（1,919 vs 15,045 回/行/seed）。同点の行では抽選が Harm を 1/8 の確率で選び、アクチュエータがそれを係争中の隣人に向ける。つまり規範ビットは状態空間を割って訓練の薄い行を作り、その行の同点抽選が Harm を増やす — **学習された制裁ではなく、白紙の表の探索と語彙の帰結**（EXP-003 の「貪欲の固定化」と同じ家族の人工物）。
3. **体力項は何も変えない（P8 の反証）。** W1 − LE は E_L +0.0014 [−0.0000, +0.0030]、加害死 +0.03、S′ −0.10（CI は 0 を含む）。W0 − LE0 は Rest +0.042（EXP-003 の副作用の再現）で E_L は同じ。制裁の痛み（−40 報酬単位）は、侵害の採集から数 tick〜数十 tick 遅れて、別の行の別の行動の後に届く。Q 更新は痛みの tick の行動に帰属させ（1 段の TD）、割引 γ = 29/32 の地平線（≈ 10 tick）では侵害の採集まで戻らない。**制裁が報酬に入っても学習者は侵害を避けない**: 報酬の経路（HYPOTHESES の「制裁が痛いことを報酬に返す」）だけでは足りず、信用割当（適格度トレース、先占者のいるセルで採ったことの記憶ビット）が要る。Phase 5 の設計問題。
4. **Enforcer の存在そのものは侵害率を上げる（LE0 − L0 = +0.0064 [0.0050, 0.0078]）。** Forager 等価の Enforcer は豊かなセルに集まり先占者になるので、学習者の採集が侵害になりやすい。LE0 の序盤の E_L 0.096 は L0 の 0.075 より高く、後半に 0.080 まで下がる（LE0 だけが「持続」の定義を 12/30 で満たす = 学習の漂移）。Learner は L0 より 87 体少ない（Enforcer 172 体の分）。
5. **N-rand は tick 2,000 まで生きない。** E_R は生涯で 0.014〜0.031 と学習者より低く（一様な歩行は先着者と共在しにくい）、生涯後半は崩壊する集団で 6/10 シードが前半の半分未満（共在が減る）。「E 一定」の予測は密度の効果を見落としていた。可決 4 件（seed 2: 2、4・7: 1）は 4-5 の帰無モデルの計測と同じ死にかけの議会で、R の規則は H1 の窓に無関係。S′ は 0.42〜1.10 だが加害のうち係争者に当たったのは 0.7〜2.4%（一様な Harm が係争者に当たる偶然）。
6. **通信なしは LE と「同じ」ではない（P6 の反証、SESOI 未満）。** N-nocomm − LE の E_L は +0.0015（CI [0.0003, 0.0026]）、S′ は 3.00 vs 3.30、Enforcer の制裁 3.93 vs 4.62 件/tick、Learner 941 vs 1,038。`Heard` の記憶がないと Enforcer の `recent`（8 枠）に `Sanctioned` が長く残り、「同じエピソードに 1 回」の歯止めが効いて重ね撃ちが減る。差は記憶の枠の競合（ADR-0014 D3 の追記「記憶の競合」）であって通信の機能ではない。
7. **記憶なしは制裁を増やす（P7）。** Enforcer が同じ係争者を毎 tick 殴り S′ 4.05（+23%）。E_L −0.0018、Learner −46 で、除去の上積みは小さい（S は 0.964 で天井）。
8. **N-blind が LE より少し高い（+0.0048）のは学習者の制裁が消えた分**（1.36 → 0.15 件/tick）で、Enforcer の制裁はむしろ多い（6.99 vs 4.62 件/tick: Learner が多く違反も 3.16 件/tick と多い）。Learner は 1,397 体（LE 1,038）、谷も 167〜237 体と浅い（LE 58〜122）。**LE の深い谷と小さい集団の 3 分の 1 ほどは学習者どうしの「制裁」（語彙の帰結）が作っている。**
9. **布告 tick 0 は谷を深くする。** LE / L1 / N-nocomm / N-nomem / W1 の谷は 53〜122 体（規則なしは 154〜386）。LE で 1,000 体に戻るのは 27/30 シード（tick 1,500〜17,900）。絶滅は出なかったが、同じ設計で seed を増やせば出うる。
10. **密度の交絡。** E_L は共在の率なので小さい集団ほど低く出る（L1 の回復とともに上がる、N-rand の崩壊とともに下がる）。LE の Learner は LE0 の 70% で、密度だけでどれだけ下がるかは本実験では分離できない。ただし L1（Learner 1,045 体 ≈ LE の 1,085）の E_L は 0.047 で LE の 0.013 より大きく、密度だけでは LE の低下（0.080 → 0.013）を説明しない。
11. **P3 は実装の検査として成立**し、N-nosanction（= LE0）vs LE の差 −0.0689 はすべて制裁の経路に帰属する。

### 限界（事後に分かったものを追加）

- 事前の限界（Enforcer は設計者の知識、体力項 0 では制裁が報酬に入らない、構成の維持は実験者の介入、N-nosanction ≡ LE0、布告 tick 0、到着順の侵害、S′ > 1、学習者の制裁は語彙の帰結、10 シードの CI、スモークの開示）はそのまま。
- **密度の交絡**（読み 10）: 腕間で Learner の個体数が 30% 違うので、E_L の差には密度の差が混じる。密度を揃えた対比（同じ個体数の窓だけを比べる、または `ScaleFood` で密度を操作する）は本実験に無い。
- **個体単位の追跡が無い**: 侵害者が死んだのか、生き残った学習者の侵害率が下がったのかを、集団の率からは分けられない（`Violated` の記録は OFF、`Acted` も OFF）。「除去」の読みは死因・個体数・時間構造・W1・N-blind からの推論。
- **死因は方策別に無い**: 加害死には Enforcer（学習者の Harm の対象にもなる）が含まれる。
- **行 64〜127 の同点の読み**（読み 2）は `_qpolicy.csv` の `tie` 列（最上位が同点の学習者の数）からの推論で、白紙の行か訓練済みの同点かは区別していない。
- **W1 / W0 は 10 シードの探索的な腕**で、体力項の重みは 2 の 1 点。
- **E_L の序盤の窓は LE / L1 では回復の途中**（LE は tick 2,000 で 1,000 体に届かないシードがある）。
- tick/s は参考値。

### 次の問い（EXP-005 以降の候補。決定は ADR で）

1. **除去と学習を個体単位で分ける**: 侵害者 id の計数（`TickReport` に侵害者ごとのヒストグラム、または `Violated` の記録 ON の短い run）で、制裁を受けた個体の生存と、生き残った個体の侵害率の変化を直接測る。Phase 5 の実験基盤（PRODUCT の Phase 5 ダッシュボード）の最初の指標候補。
2. **学習者が従うための信用割当**: 体力項では足りない（読み 3）。適格度トレース、先占者のいるセルで採ったことの記憶ビット（`ENCROACHED_RECENTLY`）、γ を長くする。いずれも ADR の決定事項（Phase 5）。
3. **Harm のアクチュエータの語彙を格子の軸にする**（係争者優先 / 最寄り / 無作為）: 学習者の「制裁」と深い谷の 1/3 はこの語彙の帰結（読み 2・8）。H2 の格子（ADR-0014 の帰結）に `standing_ticks`・制裁コスト・密度とともに入れる。
4. **布告の tick**（0 / 谷の後 2,000）と **密度の統制**（読み 9・10）。
5. **Enforcer の立法（`enforcer_motions: true`）で同じ指標を取る**: 布告でなく議会で成立した規則が同じ効果を持つか（4-5 では tick 51 に可決）。制度の「手続き」の最初の実験。
6. **製品の制度世界に `enforcer_share` を入れるか**（4-9 / 4-10、ADR-0014 D11 の追記）。
