## 問い

EXP-002 は制度を入れる前の世界について 3 つの前提条件を示した（RISKS R8 / R9、ADR-0014 の文脈）: (1) Learner 32 行の死因の 43% が加害死で、Harm の決定割合は探索 ε = 5% の床そのもの、(2) 加害は体力を減らすがエネルギーを減らさないので、制裁は Learner の報酬に現れない、(3) 空腹・在庫なし・足元に食料なし・隣接なし（行 9）で Learner は 10/10 シードで Rest を選ぶ（「飢えながら休む」）。

ADR-0014 D10 はこれを「`WorldConfig::default()` を変えずに、制度世界の既定 `WorldConfig::nomos_preset()` を**選ぶ**問題」として扱う。本実験が答える問い:

1. **加害死は ε の帰結か。** ε を 50‰ → 10‰ → 0 と下げると加害死の割合は単調に下がるか。`harm_cost` を 2,000 → 8,000 にしても下がるか（探索由来なら下がらないはず: ε の抽選は Q を見ない）。
2. **体力項は「飢えながら休む」を消すか。** `learner_health_weight` = 2（報酬 = Δエネルギー/100 + 2 × Δ体力）で行 9 の貪欲 Rest が消えるか。
3. **ε 0 の Learner は帯域に届くか。** 探索が白紙の表の同点抽選と継承だけでも、絶滅せず Forager の帯域の 70% に届くか。
4. **固定方策の侵害率 E₀。** 規則のない世界で Forager と Learner の侵害率（先占者以外の採取 / 採集）はいくらか。EXP-004 の「規則なし」のベースライン。
5. **128 行・新ビット順は学べるか。** `OCCUPIED` で行が割れる 128 行（規則がないので `VIOLATOR_ADJACENT` / `ACCUSED` は常に 0 = 実質 64 行）が、EXP-002 の旧 128 行より速く 32 行並みに回復するか。EXP-004 は 128 行を使う。

そして事前登録した決定規則で `nomos_preset` の 3 値（ε、`harm_cost`、`learner_health_weight`）を確定する。

## `nomos_preset` の決定規則（事前登録）

候補は主格子の 12 セル。条件:

- (a) 絶滅 **0/10**
- (b) 窓平均の 10 シード平均 ≥ **918**（= EXP-002 の F の 70%）
- (c) 窓の加害死（10 シード合算）≤ 窓の死因の **10%**

(a)〜(c) をすべて満たすセルのうち、次の順で 1 つに絞る:

1. **ε が最大**のもの（探索を残せる最も暴力的でない世界）。
2. ε が同点なら、**行 9 の Rest 多数派のシード数（M13）が ≤ 5/10 になる体力項**を選ぶ（その ε の候補セルのうち同じ w のセルがすべて ≤ 5/10 なら、その w は条件を満たす）。両方の w が満たす、またはどちらも満たさなければ **w = 0**（体力項は Learner の目的を変え EXP-002 と比べられなくなるので、要らなければ入れない）。
3. それでも同点なら **`harm_cost` 2,000**（既定の物理）。

どのセルも満たさなければ **ε 0・`harm_cost` 8,000** を採り（w は規則 2 で決める）、満たせなかったことを記録する。この規則は `summarize.py` の `decide()` が機械的に適用する。選んだ値は `WorldConfig::nomos_preset()`（`cz run / sweep / fork --preset nomos`）に書き、EXP-004 はこの preset から始める。EXP-004 の仕様コミットの前に preset × 128 行を 3 シード × 20,000 tick でスモーク（絶滅なし）する。

## 既知の限界（事前）

- **格子は 3 × 2 × 2 の 12 点**で、主格子は 32 行だけ。ε は 10‰ の 1 点で 50 と 0 の間を補間しない。`harm_damage`・`memory_slots`・知覚半径・グリッドは動かさない。
- **決定規則は選択の規則であって仮説の検定ではない。** 選ばれる preset は構成上「(a)〜(c) を満たす最も探索的な世界」で、それが「良い」世界であることを意味しない。w = 2 の世界は Learner の目的が EXP-002 と違う（ADR-0014 のリスク）。
- **侵害の操作的定義は到着順**（ADR-0014 D3）で、家族は共同の先占者。密集する集団ではほぼ全員が侵害者になりうる（ADR-0014 のリスク「侵害の操作化の人工物」）。E₀ はこの定義の下での値で、「所有」の何かを測っていない。
- **加害が探索か貪欲かはカーネルに記録されない。** `win_act_harm` と床の比較で間接に判定する（EXP-002 と同じ）。
- **ε 0 の探索は白紙の同点抽選と継承だけ**なので、どの行動が試されるかは創設集団の抽選に依存し、Q の固定点は初期化の人工物を含む。
- **行 9 の多数派は終了時の生存学習者のスナップショット**（EXP-002 と同じ）。窓の途中の推移は見ない。
- **体力項の算術**: Δ体力は加害・飢餓・Rest の回復をまとめて 1 つの重みで読む。加害を受けたこと（−20）と Rest の回復（+1）を分けて重み付けはできない（D3 の設計）。
- **128 行は 1 腕（既定セル）だけ**。格子の他のセルで 128 行がどうなるかは見ない（EXP-004 は preset × 128 行なので、スモークで絶滅しないことだけ確認する）。
- **統計**は 10 シードの記述統計（平均・sd・CV・合算比・対の勝敗数）のみ。信頼区間・検定は出さない。
- 実行時間は `cz sweep` の総時間で参考値。

## 死の終端報酬を腕にしない理由（ADR-0014 D10 のとおり）

EXP-002 の「次の問い」1 は「負の終端報酬を与えた Learner で行 9 の Rest が消えるか」だった。本実験はそれを腕にしない:

- Learner の Q 表は個体の `params.table` にあり、**個体の死と一緒に消える**。子は出生時点（親の生存中）に親の表を複写済みで、親の死後の表は誰にも読まれない。
- 死の時点で表に終端更新（`Q[s, a] ← r_terminal` など）を施しても、更新された表はその tick の Phase 6 で捨てられる。個体内学習では構造的に無効。
- 集団で共有する Q（死んだ個体の表を集団に反映する）は ADR-0013 で却下済み（方策は個体の純関数で、共有状態は決定論と並列 decide を壊す）。
- 代わりに、**死の前に効く信号**として報酬の体力項（`learner_health_weight`、D3）を腕にした。飢餓ダメージ（体力 −5/tick）は死の最大 20 tick 前から報酬に現れる。ただし P3 の対立予測のとおり、地平線 10 tick の割引ではそれでも遠い可能性があり、その場合は「終端報酬でも体力項でも行 9 は消えない」が本実験の結論になる（餓死は −5 の連続と Consume の不発としてしか学ばれない、の再確認）。

### 読み（事後の解釈。事前登録の判定ではない）

1. **加害死は ε に単調だが、ε 0 でも消えない（1.4〜5.8%）。** ε 0 の Harm の決定割合 0.0004〜0.0017 は探索ではなく貪欲な選択である。候補の機構は**貪欲の固定化**: 探索がないと、ある行で先に試されて Q が正に出た行動が選ばれ続け、他の行動の Q は白紙（0）か古い値のまま更新されない。Harm の即時報酬は −25（`harm_cost` 2,000 ÷ 100 + 代謝 5）だが、Q 更新は次状態の max Q を γ = 29/32 で割り引いて足すので、食料の上に立つ行（max Q ≈ +400 報酬単位）から 1 回で正の値になりうる。`harm_cost` 8,000（−85）ではその余地が小さく、ε 0 の加害は 2.33 → 0.68/tick、加害死 5.7 → 1.4% に下がる（P1c の反証の中身）。ε 50 では `harm_cost` がほぼ効かず（−2.2 / +0.6 pt）、EXP-002 の「加害は探索の床」の読みは ε 50 に限って正しい。ε 10 は中間（Harm 0.0019 のうち床 0.0012 + 貪欲 ≈ 0.0007、`harm_cost` で −4 pt）。
2. **体力項は「飢えながら休む」を消さず、Rest 全体を増やす。** 行 9 の Rest 多数派は w = 2 でも 9〜10/10 のまま。Rest の決定割合は w 0 → 2 で ε 50: 0.083 → 0.159、ε 10: 0.095 → 0.160、ε 0: 0.139 → 0.185。対立予測の機構と整合する: 割引の地平線（約 10 tick）は空腹帯（Rest で約 100 tick）の大半から飢餓状態を見せず、Rest の回復 +1 は体力 < 100 の個体に +2 の報酬を返す。副作用として ε 50 の加害死の割合は 43 → 34% に下がった（Rest が増えて体力が回復し、加害の累積で死ぬ個体が減る、が候補。事前登録の指標ではない）。**死の終端報酬（構造的に無効、D10）も体力項も行 9 を動かさない**ので、「飢えながら休む」は報酬の時間構造（γ と状態の分解能）の問題として Phase 5 に送る（「次の問い」）。
3. **帯域は ε に対して山型（事前登録なし）。** 窓平均は ε 0: 1,513〜1,610、ε 10: 1,593〜1,708、ε 50: 1,502〜1,663 で、ε 10 のセルが最も多い。差は CV（0.04〜0.12）と同程度で、10 シードでは「探索が少ないと貪欲の固定化、多いと加害死」という読みの候補にとどまる。
4. **E₀（規則なしの侵害率）は F 0.122 > L32 0.102 > L128 0.078。** 主格子では ε 0 が 0.113〜0.119、ε 50 が 0.100〜0.108、ε 10 が 0.096〜0.099 で単調ではない。Forager は視界で最も豊かなセルへ集まるので最も高い。`OCCUPIED` を見る 128 行の学習者が最も低いのは、同セルに先着者がいる行（16〜23 = 隣接あり・視界に食料なし）で貪欲行動が `OCCUPIED` 0 の行と一致しない（一致 0〜3/10 シード）ことと整合するが、これは採集の競合負け（`LostContention`、採集 −2 の不発）を避ける学習が先占の定義と重なるためと読むのが自然で、**規範の学習ではない**（規則は 1 つもない）。EXP-004 の L0（規則なし、128 行）がこの値の対照になる。
5. **新ビット順の 128 行は 32 行と同じ速さで戻る。** 谷は tick 200 に 155〜242 体（EXP-002 の旧 128 行は 76〜116 体）、tick 1,000 の生存数は既定セルの 1.04 倍、窓平均 1,615 ≈ L32 1,623。規則のない世界では `VIOLATOR_ADJACENT` / `ACCUSED` が常に 0 で、`OCCUPIED` は `ADJACENT` を含意する（同セルの先着者は隣接個体でもある）ので、到達できる行は 32 + 16 = **48 行**（行 41 = `occupied` 1 かつ `adjacent` 0 は 10 シードとも未訪問）。EXP-002 の旧 128 行（`UPPER / HEARD` で 4 倍に割れる）より白紙が少ないのが速さの理由と読める。D6 の既定 32 行は据え置き、EXP-004 の 128 行は学習速度の面で支障がない。128 行の加害死 48.8%（Harm の決定割合 0.0061 は床どおり）と行 9 の Rest 多数派 4/10 は 32 行（43.2%、10/10）と違うが、機構は本実験では特定できない。
6. **P0 の全行一致**は、4-2 / 4-3 のカーネル変更と `--harm-cost` の CLI 変更（既定値を `WorldConfig::default()` から取る）が既定世界の遷移を 1 bit も変えていないことの、20,000 tick × 10 シード × 2 方策での回帰検査である。

### 限界（事後に分かったものを追加）

- 事前の限界（12 点の格子、決定規則は選択の規則、侵害の操作的定義、探索か貪欲かは記録されない、ε 0 の初期化依存、行 9 は終了時のスナップショット、体力項の算術、128 行は 1 腕、記述統計のみ）はそのまま。
- **(c) の門の余裕が薄い**（8.2% vs 10%、最悪シード 9.0%）。preset の ε は 10 シードの選択の結果で、ε 10 と ε 0 の間は補間していない。
- EXP-002 の「探索の床」の読みは **ε 50 に限って**成り立つ。ε ≤ 10 では貪欲に選ばれる Harm が残り、その量は `harm_cost` に依存する（読み 1）。
- M13 の 128 行の第 2 行（行 41）は構造的に未訪問で、指標として空振り（読み 5）。
- 体力項は加害・飢餓・回復を 1 つの重みで読むので、「加害が痛い」だけを報酬に入れる設計（4-1 の D3）とは別の実験になる。
- tick/s は参考値（単一スレッド。`cz sweep` の総時間で系列の書き出しを含む）。

### 次の問い（EXP-004 以降の候補。決定は ADR で）

1. **EXP-004（H1）は preset (10, 2000, 0) × 128 行から始める**（ADR-0014 D11）。規則なしの E₀ は 128 行で 0.078（32 行 0.098〜0.102、F 0.122）。学習者の加害は床（ε 10 で ≈ 0.0012）+ 貪欲の残り（≈ 0.0007）で、制裁の S' の床はここから見積もる。
2. **行 9（飢えながら休む）**: 終端報酬も体力項も効かない。候補は γ を長くする（地平線 ≫ 空腹帯）、`UPPER` ビット（512 行）で飢餓の手前を別の行にする、失敗行動のコスト（RISKS R9）。いずれも ADR の決定事項で Phase 5。
3. **ε 0 の貪欲の固定化**: 楽観的初期化や訪問回数に基づく探索は Phase 5 / 6 の学習方策の設計問題。EXP-003 では ε 0 を製品の既定にしない理由（固定化で Harm が残る）として記録する。
4. **体力項の副作用**（Rest の増加、加害死の減少）は、制裁が「痛い」ことを報酬に入れる経路として EXP-004 の後に再検討する（S' が床から動かなければ、報酬の経路の問題として Phase 5 の最初の設計問題になる、ADR-0014 の帰結のとおり）。
