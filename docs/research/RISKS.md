# 研究上のリスクと対策

## R1. 事前定義した行動から、どこまで「創発」を検証できるか

**問題**: 行動集合・観測・DSL の文法はすべて設計者が決める。所有権に相当する行動（排除・制裁）を表現できる語彙を与えれば、所有権「らしき」現象は出やすくなる。表現力の空間そのものが事前分布になる。

**対策**
1. 主張の単位を「X が出現した」ではなく「条件 C のとき、ベースライン B と比べて指標 M が有意に変化した」に限定する。
2. 行動語彙は**汎用プリミティブ**（Move/Gather/Transfer/Attack/Signal/Propose…）に留め、"Own"・"Claim" のような制度名の行動を作らない。
3. 必須の帰無モデル: (a) ランダム方策、(b) 通信を無効化、(c) 記憶を無効化、(d) 制裁コスト無限大。制度指標が帰無モデルでも同程度に出るなら創発とは呼ばない。
4. 制度の判定は**行動履歴と規則運用ログから計算する操作的指標**で行う（例: 所有権指標 = 「最初に資源へ到達/投資した個体以外の採取が、制裁確率の上昇と結びつき、かつ時間とともに減る」）。LLM による解釈を証拠にしない。
5. 指標・閾値・比較条件を実験前に `docs/research/experiments/` へ固定（事前登録）。

**EXP-004 の計測（2026-10-18、`docs/research/experiments/EXP-004-first-occupant-norm.md`）**: 対策 1〜5 のとおり主張を「条件 LE で指標 E_L が同じ seed の LE0 より 0.0669 下がった（30 シード、CI [−0.0684, −0.0654]）」に限定し、帰無モデル (a)〜(d) を走らせた。差は規則と制裁の経路に帰属した（制裁できない規則は LE0 と物理が同一）が、**機構は侵害者の除去**（加害死 13% → 57%、Learner −30%）で、学習者が規範を学んだ証拠はない（制裁の痛みを報酬に入れた腕も規範情報を見ない腕も同じ値）。R1 の懸念は 2 つの形で現れた: (i) 制裁を担う `Enforcer` は設計者の知識そのもので、その効果は「従わせる個体を置けば侵害者が減る」以上を意味しない。(ii) **行動語彙の設計が指標を動かす**: Harm のアクチュエータが係争中の隣人を先に狙う（ADR-0014 D6）だけで、学習者の探索の加害の 33〜65% が「制裁」として係争者に集中し、学習者だけの世界（L1）でも侵害率が 3 分の 1 下がり集団が 3 分の 1 減る。規範ビットが割った訓練の薄い行の同点抽選が 1 体あたりの Harm を 1.45 倍にする（白紙の表の探索）。制度の指標を読むときは、語彙（誰を殴るか）と探索（白紙の行）の帰結を帰無モデル（N-blind がそれ）で切り分ける。

## R2. 決定論的再実行と並列化の両立

**対策（実装済み）**: Decide を純関数化 → 順序保存の並列 map。乱数は座標関数。Apply は単一スレッド・固定フェーズ。整数演算のみ。`parallel_decide_matches_serial` テストで bit 一致を検証。

**残課題**
- Apply の並列化（10 万体超で律速になりうる）: 空間を固定タイルに分割し、タイル内競合のみを並列解決、タイル跨ぎは決定論的な二段階で処理。必要と**計測で**示されるまで行わない。
- 認知層が浮動小数点を使う場合: Intent をイベント台帳に記録し、再生は記録から行う（ADR-0003）。
- 現在の 100k 体ベンチで serial 2.26 ms → parallel decide 1.28 ms。Apply 側の比率は未計測（プロファイル TODO）。

## R3. エージェント数増加時の性能劣化

**現状の計測**（docs/STATUS.md）: 1 体あたりの step コストは 1k→100k で約 21 ns → 37 ns に増加（キャッシュミスと推定、未プロファイル）。

**対策候補（計測で必要と示されてから実施）**
- Gather 請求のソートをセル単位のバケットに置換（O(n log n) → O(n)）。
- エージェントの空間インデックス（Phase 3 で他者観測を入れる時点で必須）: 一様グリッドバケット、tick ごと再構築。
- 視界走査のコスト: 半径 r で O(r²)。r を上げる実験では資源の積分画像/占有ビットマップを検討。
- エージェントを位置順に定期ソートしてキャッシュ局所性を改善（ただし正準順序は id 順を保つため、別インデックスで）。

## R4. エージェントの行動と世界の状態遷移の分離

**対策（実装済み）**: `Observation`（読み取り専用ビュー）→ `Intent`（行動 + 記憶更新）→ カーネルが適用。方策は世界を直接変更できない。`Failure` は物理的不能のみ。

**Phase 4 への含意**: 制度は「物理法則」を変えず、(a) エージェントの観測に規範情報を加える、(b) 制裁などの行動を他者に起こさせる、の 2 経路でのみ作用する。カーネルに「禁止された行動を実行不能にする」仕組みは入れない。

## R5. 将来の制度 DSL に備えて今抽象化すべきもの

今やるもの（最小）:
- **行動の結果を構造化して残すこと**: `TickReport` は集計のみ。Phase 2 のイベント台帳で `(tick, agent, intent, outcome)` を記録する。規範の違反判定はこの台帳の上で行う。
- **エンティティ ID の永続性**: 実装済み（再利用しない単調増加 id）。契約の当事者参照に必要。
- **行動語彙の拡張点**: `Action` enum に Transfer / Signal を追加できる形を維持。

今やらないもの: Institution 型、規範インタプリタ、合意プロトコル。必要な形は Phase 3 の通信・交渉実験の結果で決める。

## R6. Phase 3 で加わるリスク（ADR-0013）

- **加害行動の退化均衡**: `Harm` を入れると、学習が「殴り合って絶滅」や「最強者の独占」に収束しうる。結果として記録し、デモの既定ではコストを高めに置く。制裁として機能するかは Phase 4 の制度次第。
- **報酬ハッキング**: Learner の報酬は自己エネルギーのみ。移転は損なので分かち合いは出ない想定。出ないことを失敗と扱わない（Phase 4 の前提条件）。
- **解釈可能性**: 方策の内部が見えなくなる。インスペクタに重みの要約・Q の上位行動を出し、台帳の相互作用から行動を説明できる形を保つ。
- **スナップショットの肥大**: 記憶と Q 表で数倍になる。巻き戻し時間を再計測し、間隔を調整する。

## R7. その他の指摘

- **人口動態のパラメータ依存**: 出生（エネルギー分裂）と寿命は ADR-0008 で導入し、既定設定では 10 シードすべてが約 1,250〜1,365 体の帯域に収束した（EXP-001）。ただし帯域の位置も収束の有無も、再生量・代謝・出生閾値という設計者の選択で決まる。制度の実験では、人口が帯域に入っている区間だけを分析対象にし、帯域外（絶滅・爆発）の設定は別扱いにする。
- **Forager 方策は設計者知識そのもの**: Phase 3 では学習方策と比較し、Forager は上界参照としてのみ使う。
- **H4（因果）の範囲**: 介入効果はモデル内部の因果効果であり、現実社会への一般化は別論点。報告時に必ず区別する。
- **乱数品質**: SplitMix64 の統計検定は未実施（ADR-0004）。

## R8. 加害行動が生む退化均衡（Phase 3 の計測、ADR-0013 3-10）

**観測（EXP-002、既定世界、10 シード、`docs/research/experiments/EXP-002-learning-vs-fixed.md`）**
- Reflex（突然変異 ON）: 加害 0.76〜1.72 件/tick、加害死は窓の死因の 8.2%。絶滅は 0/10。
- Learner 32 行: 加害の決定割合は 0.58% で探索の床（ε 5% × 1/8 × 隣接のある割合）そのもの、つまり貪欲には選ばれていない。それでも 1,600 体 × 0.58% ≈ 9.5 加害/tick、`harm_damage` 20 で約 1 死/tick となり、**加害死が死因の 43%**（128 行では 54%）。
- 「殴り合って絶滅」は起きなかった（絶滅 0/10）が、制裁のない世界が既にこの暴力水準にある。

**含意**
- Phase 4 の制度実験では、加害死 43% が「制裁なし」のベースライン。制裁が加害を減らすかは、この水準からの差で判定する（H1 の制裁の条件付き確率）。
- 既定の ε = 5% は暴力の主因なので、製品のデモ世界の既定（R6「コストを高めに置く」）は ε と `harm_cost` の格子（EXP-003 候補）で決める。現状の既定で「Learner は暴力的」と読むのは探索パラメータの帰結であって学習の帰結ではない。
- Reflex の `hunger_permille` が 10/10 シードで低下した（500 → 平均 389、50k tick で 206）のは選択が働いた可能性があるが機構は未特定（EXP-002 の読み 7）。進化の「方向」を主張するには `--mutate` だけの Forager との比較が要る。

**EXP-003 の計測（2026-10-17、`docs/research/experiments/EXP-003-baseline-grid.md`、Learner 32 行、`nomos` オン・規則なし、ε × `harm_cost` × 体力項の 12 セル × 10 シード × 20,000 tick）**
- 加害死の割合は ε に単調: ε 50 で 33.6〜43.2%、ε 10 で 3.7〜8.2%、ε 0 で 1.4〜5.8%。**ε 0 でも 0 にならない**: 探索がなくても、先に試されて Q が正に出た Harm が選ばれ続ける（貪欲の固定化。Harm の決定 0.0004〜0.0017）。`harm_cost` 8,000 は ε ≤ 10 の加害を減らす（ε 0 で 2.33 → 0.68/tick）が ε 50 では効かない（探索は Q を見ない）。「加害は探索の床」は ε 50 に限って正しい。
- 製品のデモ世界と EXP-004 の既定は `WorldConfig::nomos_preset()` = `nomos` オン・ε 10‰・`harm_cost` 2,000・体力項 0（事前登録した決定規則。門の余裕は薄い: 加害死 8.2% vs 10%、最悪シード 9.0%）。128 行の学習者ではこの preset でも加害死 12.9%（3 シード）で、これが H1 の「制裁なし」の暴力水準になる。「殴り合って絶滅」は 12 セルとスモークのどこでも起きていない。

**EXP-004 の計測（2026-10-18、`nomos_preset` × 128 行、先占規範を tick 0 に布告）**: 制裁は暴力そのものなので、規則のある世界は規則のない世界より暴力的になる — LE（Enforcer 10%）で加害死が死因の **57.2%**（LE0 13.4%）、学習者だけの L1 でも 27.9%（L0 12.9%）。L1 の加害の件数は L0 と同じ（3.96 vs 4.20 件/tick）なのに係争者に集中するので死ぬ。谷は 53〜122 体（規則なしは 154〜386）で絶滅はなかった（30 + 10 × 5 シード）が、同じ設計で seed を増やせば出うる。「殴り合って絶滅」は規則が招きうる退化均衡として、`standing_ticks`・制裁コスト・密度の格子（H2）で境界を測る。

**Phase 4 完了時点の扱い（2026-10-18、4-10）**: 製品の制度世界（`WorldConfig::institution_preset()` = `nomos_preset` + 128 行 + 出生で Enforcer を 10% に保つ割当。公開 URL の `?nomos=1&policy=institution`）はこの退化均衡の手前にある: seed 42 では議会が tick 51 に先占の規範を可決し、生存は 1,000 → tick 300 に 104 体（白紙の表の餓死 684 + 制裁の加害死 492）→ tick 3,000 に 982 体へ回復する（STATUS「観察された挙動（製品の制度世界）」、TUTORIAL §11）。制度世界の加害死の割合は定常でも死因の 0.57（EXP-004 の LE）で、規則のない世界（0.13）の 4 倍。これは「制度が従わない学習者を殺して減らす」世界であって、暴力が減る世界ではない。制裁のコスト（`harm_cost`、`standing_ticks`、Enforcer の割合）を軸にした境界の計測は Phase 5 の H2。

## R9. 報酬ハッキングと報酬設計（Phase 3 の計測）

**観測**
- Transfer / Signal / Store が貪欲に選ばれる行は、食料が視界にない「訪問の薄い行」に限られ、無料または微小コストの行動の同点が原因。分かち合いや通信の学習ではない（P5f の事前登録どおり）。Signal は `signal_cost` 0 で Rest と報酬で区別がつかない。
- **「飢えながら休む」**: 空腹・在庫なし・足元に食料なし・隣接なし（行 9）で Learner は 10/10 シードで Rest を選ぶ。D6 が死に終端報酬を与えていないため、餓死は −5 の連続でしかなく、探索して死ぬより休む方が Q 上は得になる。
- Reflex は在庫なしでも Consume を 28% 選ぶ（不発は無料）。失敗行動のコストが 0 だと、重みの漂移はそれを罰しない。

**対策（候補。実施は事前登録で）**
- 終端報酬の有無を EXP-003 で比較する（D6 で先送りした項目）。
- 失敗行動（在庫なしの Consume、対象なしの Transfer / Harm）に小さなコストを置くかは、物理の変更なので ADR で決める。Forager のゴールデンに影響する可能性があり、変えるなら旧定義で遷移不変を証明できない（遷移そのものが変わる）ので、ゴールデン表に理由を残す。
- 報酬は自己エネルギーのみを維持する（分かち合いが「割に合う」条件を作るのは Phase 4 の制度）。

**EXP-003 の計測（2026-10-17）**
- 死の終端報酬は腕にしなかった（ADR-0014 D10: Q 表は個体と一緒に消え、子は出生時に複写済みなので構造的に無効）。代わりの体力項（`learner_health_weight` 2）は**行 9 の Rest を消さない**（w = 2 の 6 セルで 9〜10/10 シードが Rest のまま。事前登録の対立予測が成立）。Rest の決定割合はむしろ約 2 倍（0.08 → 0.16）: Rest の回復 +1 が w 倍の報酬になり、割引 γ = 29/32 の地平線（≈ 10 tick）は空腹帯（Rest で ≈ 100 tick）の大半から飢餓状態（−10/tick）を見せない。副作用で ε 50 の加害死は 43 → 34%。
- 残る候補は γ を長くする、`UPPER` ビット（512 行）で飢餓の手前を別の行にする、失敗行動のコスト（上の候補）。いずれも ADR の決定で Phase 5。

**EXP-004 の計測（2026-10-18、副次腕 W0 / W1 = 体力項 2、10 シード、`docs/research/experiments/EXP-004-first-occupant-norm.md`）**
- 制裁の痛み（−20 体力 × 2 = −40 報酬単位）を報酬に入れても学習者は侵害を避けない: W1 の学習者の侵害率は LE と同値（0.0141 vs 0.0127、対の差 +0.0014 [−0.0000, +0.0030]）、加害死の割合も同値（0.60 vs 0.57）、制裁の S′ も同値（3.20 vs 3.30）。痛みは侵害の採集から数 tick〜数十 tick 遅れて別の行の別の行動の後に届き、1 段の TD と γ = 29/32（地平線 ≈ 10 tick）では侵害の採集まで戻らない。
- したがって「制裁が痛いことを報酬に返す」経路だけでは足りず、**信用割当**（適格度トレース、先占者のいるセルで採ったことの記憶ビット `ENCROACHED_RECENTLY`、γ）が Phase 5 の最初の設計問題（ADR-0014 の帰結の追記、HYPOTHESES の Phase 5 への引き渡し）。W0（規則なし + 体力項 2）は Rest の決定割合 +0.042 で EXP-003 の副作用を再現し、行 9 は動かない。

## R10. 解釈可能性（Phase 3 の対策と限界）

**対策（実装済み）**
- `cz sweep` の `<out>_qpolicy.csv`（Q 表の行ごとの貪欲行動の個体数）、行動構成（8 種の決定割合）、\|Q\| と窓の ΔQ、重みの漂移と `hunger_permille` の統計（3-8）。
- インスペクタの last step（行・行動・報酬）と Q 行、記憶と台帳、交渉スレッド（3-9a〜3-9c）。
- 食料が視界にある 16 行は 10 シードで同じ方策に収束しており、表として読める（EXP-002 の読み 6）。

**限界**
- 行ごとの**訪問回数**を記録していないので「訪問の薄い行」は推定。`q_delta_window` は世代交代と訪問の薄い行の揺れを分けられない。
- Reflex の重み（16 × 8）は漂移の大きさしか要約しておらず、どの特徴が決定を変えたかは読めない。
- 学習者の行動を台帳の相互作用から説明する経路は残しているが、「なぜその行動か」は Q 表の数値以上には答えられない。

## R11. スナップショットの肥大（計測値）

- tick 1,000 のバイナリ: Forager 61 KB（1,316 体、約 20 B/体）、Reflex 初期重み 259 KB（167 B/体）、Reflex 進化後 335〜375 KB（231 B/体）、**Learner 32 行 540 KB（1,443 体、351 B/体）**、Learner 128 行は 1 MB 超（既定にしない）。ADR-0013 の「1,300 体 ≤ 1 MB」は既定設定で満たす。
- 巻き戻し（2b-4）の最悪シークはスナップショット間隔分の再実行で決まり、復号は Forager で 0.7 ms。**学習世界での再計測は未実施**（Learner 世界の復号と再実行の時間は STATUS に無い）。3-9c の公開 URL 確認では tick 600 へのシークが体感で問題なかったが、数値は測っていない。
- **4-9 の計測（2026-10-18、M1、ADR-0014 完了条件 2）**: バイナリスナップショットは Learner 32 行 1,443 体で 541,802 B（復号 5.34 ms、native）、**制度世界（`institution_preset`、128 行、Enforcer 10%）989 体で 1,047,996 B（復号 11.27 ms）**、1,130 体で 1,203,213 B — 128 行の Q 表（2 KB/Learner）が主で ≈ 1,060 B/体、門（既定 ≤ 1 MB、制度世界 ≤ 2 MB）の内側。巻き戻しの最悪（間隔 250 の直後 = 249 tick 再実行。スナップショットは `multiverse` がメモリ上に `World` の複製で持つので復元は 0.02〜0.1 ms、復号は fork の経路だけ）は node（V8、公開ビルドのプロファイル、`web/scripts/bench-seek.mjs`）で **学習世界（1,428 体）115 ms、制度世界（1,130 体）98 ms、Forager 51 ms**、fork の復号（`fromSnapshot`）は 5.9 / 14.3 / 0.4 ms — 門 ≤ 200 ms の内側。サイズ最適化 `s` ビルドでは 127 / 110 / 56 ms。ブラウザ前面（採用ビルド、学習世界 1,581〜1,647 体、rAF 60 Hz の秒）では **171〜177 ms**（3 回、header の `last seek`）、fork は 51 ms（forager → learner）/ 94〜103 ms（制度世界 1.05 MB、ワーカーの起動込み）、制度世界の `Go` 0 → 3,000 が 700 ms。制度世界の谷（tick 200〜400 に 100〜150 体）では 1 tick が軽いので、最悪ケースは定常帯域（tick ≥ 2,500）で読む。
- **Phase 4 完了時点の扱い（2026-10-18）**: 製品の制度世界は既定が 128 行なので、1 体あたり ≈ 1,060 B、1,300 体なら ≈ 1.4 MB の見込みで門（≤ 2 MB）の内側。fork の転送（1.05 MB）と巻き戻し（ブラウザ 171〜177 ms、node 98〜128 ms）は門 ≤ 200 ms の内側だが、Learner 32 行の既定世界（541,802 B、51〜115 ms）の 2 倍前後。間隔 250 は据え置く。wasm は公開ビルドのプロファイル（カーネルだけ `opt-level 3`、残り `z`、`wasm-opt -Oz`）で 397,333 B（門 ≤ 400 KB の残り 0.7%）。次に門に当たるときの手は serde_json を境界から外す（≈ 150 KB の見込み、TODO の Phase 5 ブロック）。

## R12. 係争の公知（Phase 4 の設計の人工性、ADR-0014 D2 / D6）

**問題**: v1 の制度では「誰が係争中か」が `NormIndex`（tick 開始時に `nomos.standing` から作る派生状態）として**全員に見える**。目撃も通信も記憶も要らず、知覚半径の外の個体の係争も、規則が立った次の tick から誰もが読める（`Perception.see_standing` は世界全体のスイッチで、個体別ではない）。現実の制度が抱える「情報の問題」— 誰が違反者かを知る、伝える、覚える — を設計が消している。これは設計者の選択であって物理の事実ではなく、制度の成立条件を問う H2 の格子では軸にしなければならない。

**計測（EXP-004、2026-10-18、`docs/research/experiments/EXP-004-first-occupant-norm.md`）**: 帰無モデル 5 本のうち 2 本が、この設計の帰結を記録しただけになった。通信なし（N-nocomm、`signal_radius` 0）の学習者の侵害率は LE と +0.0015（CI [0.0003, 0.0026]、SESOI 0.01 未満）、制裁の S′ は 3.00 vs 3.30 — 差は `Heard` の記憶がなくなって Enforcer の記憶の枠（8 件）に `Sanctioned` が長く残り「同じエピソードに 1 回」の歯止めが効く分（記憶の競合、ADR-0014 D3 の追記）で、通信が制裁に使われていないことの記録。記憶なし（N-nomem）は制裁をむしろ増やす（S′ 4.05 vs 3.25: Enforcer が同じ係争者を毎 tick 殴る）。どちらも「通信や記憶がなくても制度が成り立つ」証拠ではなく、v1 の制裁が通信も記憶も使わない（係争は公知）ことの確認である。

**対策**: 結果の解釈に必ず付記する（EXP-004 の限界、HYPOTHESES の H1 の状態）。Phase 5 の H2 の格子に、係争の知覚を個体別に制限する変種 — `see_standing` の個体別化、目撃（`EncroachedBy / SawSanction` の記憶）だけから知る係争、半径付きの地域制度 — を入れる（ADR-0014 の「却下した / 先送りした案」）。その世界で初めて N-nocomm / N-nomem は情報のある帰無モデルになる。

## R13. 先占の操作化（到着順）の人工物（ADR-0014 D3）

**問題**: 「先占者」は `Agent.arrived`（今のセルに立ち始めた tick。移動で更新、出生は親を継承、創設個体は最古）だけで決まり、「投資」（貯蔵、直近の採集、滞在の長さ）を含まない。侵害 = 同セルに自分より早く到着した生存個体がいるのに採集に成功、なので、密集する集団では誰もが侵害者になりうる。家族を共同の先占者にした選択も人工物を生む（親子は同じセルで採り続けても侵害にならない）。侵害率 E は「所有」の何かを測っておらず、この定義の下での共在の率である。

**計測（EXP-003 / EXP-004、2026-10-17 / 18）**: 規則なしの侵害率 E₀ は Forager 0.122 > Learner 32 行 0.102 > 128 行 0.078（EXP-003、10 シード、同 seed で F > L が 10/10）— 最も豊かなセルへ集まる固定方策ほど高く、`OCCUPIED` を見る 128 行の学習者が低いのは採集の競合負けを避ける学習が先占の定義と重なるため（規範の学習ではない。規則は 1 つもない）。Forager 等価の Enforcer は豊かなセルの先占者になるので、Enforcer の存在そのものが学習者の侵害率を上げる（EXP-004: LE0 − L0 = +0.0064 [0.0050, 0.0078]）。侵害は既定世界で 19〜23 件/tick（採集の 12〜19%、4-1 のスモーク）あり、`Violated` の常時記録を不可能にした（既定 OFF、ADR-0014 D9）。E は共在の率なので**密度に依る**: EXP-004 の L1 は谷からの回復とともに 0.029 → 0.050 と上がり、N-rand は崩壊とともに下がり、Learner が 30% 違う LE − LE0 の差には密度の分が混じる（L1 = 同じ密度で 0.047 なので密度だけでは説明しないが、分離はできていない）。

**対策**: 主張は差で読む（同じ seed の対、同じ定義の下）。密度を揃えた対比（同じ個体数の窓だけ、または `ScaleFood` で密度を操作）と、先占の根拠の変種（`Store` による投資、直近の採集、滞在の長さ）を Phase 5 の H2 の格子に入れる（ADR-0014 の「却下した / 先送りした案」）。侵害率を「所有権の指標」と呼ばず、画面でも `E (encroachments / gathers)` とだけ書く。

## R14. 陽性対照 `Enforcer` は設計者の知識（ADR-0014 D7 / D11、R1 / R7 の続き）

**問題**: EXP-004 の主腕 LE で制裁を担うのは台本の方策 `Enforcer`（係争中の隣人をエピソードごとに 1 回殴り、約束を守り、先占の規範を動議して賛成し、他人が先に着いたセルでは採らない。それ以外は Forager と同一）で、Forager と同じく設計者の知識をそのまま書いたものである。LE で侵害率が下がっても、それは「制度を担う個体を置けば、従わない学習者が減る条件がある」以上を意味しない。制度の「発明」（立法の学習）も「遵守の学習」も Enforcer の挙動からは何も言えない（R7 の Forager と同じ扱い）。製品の制度世界で議会が tick 51 に先占の規範を可決するのも、Enforcer の台本（規則 3〜4）が動議し賛成するからで、学習者は 1 票も投じていない。

**計測（EXP-004、2026-10-18、30 シード）**: LE の学習者の侵害率は LE0 より 0.0669 低い（95% CI [−0.0684, −0.0654]、0.080 → 0.013）が、低下の機構は Enforcer の制裁（4.62 件/tick）と学習者自身の語彙の帰結（1.36 件/tick）による侵害者の**除去**: 加害死 13.4% → 57.2%、Learner 1,541 → 1,085、谷は 58〜122 体（規則なしは 288〜386）。体力項 2 の W1 も盲目の N-blind も同程度に下がる = 学習者は従うことを学んでいない。製品の制度世界（`institution_preset`、Enforcer を出生で 10% に保つ）では seed 42 で tick 300 に 104 体まで落ちてから tick 3,000 に 982 体へ回復する（公開 URL と CLI で一致）。「制度が従わない学習者を殺して減らし、その後に回復する」世界であって、「学習者が規範に従う」世界ではない。Enforcer の割合を保つ `enforcer_share_permille` も出生時の割当という実験者の介入で、Enforcer の子として白紙の表で生まれる Learner（出生の ≈ 10%）が流入する（EXP-004 の限界）。

**対策**: Enforcer を含む条件の結果は必ず「陽性対照」と呼び、学習者だけの条件（L1）と帰無モデル（N-blind = 語彙の帰結の切り分け）を並べて報告する。学習者が制裁・立法に参加する経路（制裁の報酬経路と信用割当、投票が報酬に返る経路）は Phase 5 の設計問題で、それまで Enforcer の挙動を制度の証拠として引かない。TUTORIAL / README でも「台本」「陽性対照」と明記する。
