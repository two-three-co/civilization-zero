# 研究仮説（ドラフト・未検証）

すべて仮説。実装はこれらが成立することを前提にしない。各仮説の実験仕様は、実施前に
`docs/research/experiments/EXP-xxx.md` として指標・比較・判定条件を固定する。

共通の報告規則:
- 単一シードの結果は「事例」としてのみ扱う。主張は複数シード（初期値 ≥ 30）の分布で行う。
- 介入はシード単位でランダム割付（同一初期状態から fork し、条件のみ変える）。得られるのは**モデル内部の**因果効果。
- 効果量と 95% 信頼区間を報告。p 値のみの報告はしない。
- 失敗した予測も記録する。

## Phase 1 で検証できること / できないこと

- できる: カーネルの再現性・保存則、帰無モデル（Random）と設計方策（Forager）の生存差という**健全性チェック**。
- できない: H1〜H5 のいずれも。Phase 1 には通信・他者観測・交換・制裁がない。

## Phase 3 で検証できたこと / できないこと（EXP-002、2026-10-17）

- できた（健全性チェック、`docs/research/experiments/EXP-002-learning-vs-fixed.md`）: 学習方策（Reflex 突然変異 ON、Learner 32 行）は 10 シードすべてで絶滅せず、既定世界で Forager の個体数帯域を上回った（1572 / 1623 vs 1312。ADR-0013 D9 の「Learner ≤ Forager」は反証）。Random は 10/10 絶滅。Forager は EXP-001 と全行一致（回帰検査）。
- H1 の前提条件として: 学習者は生き残り、社会行動は台帳に載る。ただし Transfer が貪欲に選ばれるのは訪問の薄い行の同点であって分かち合いの学習ではなく（R6 のとおり報酬が自己エネルギーのみ）、加害死は探索（ε = 5%）だけで Learner の死因の 43% になる。制裁（Phase 4）を入れる前の世界が既にこの暴力水準であることを、H1 のベースライン設計で考慮する。
- できない: H1〜H5 のいずれも。所有権指標・制度・制裁はまだない。

## Phase 4 の前提条件（EXP-003、2026-10-17）

- `docs/research/experiments/EXP-003-baseline-grid.md`: 制度実験のベースライン世界を事前登録した決定規則で選んだ（`WorldConfig::nomos_preset()` = `nomos` オン・ε 10‰・`harm_cost` 2,000・体力項 0。12 セルとも絶滅なし、加害死は ε に単調だが ε 0 でも 1.4〜5.8% 残る）。規則なしの侵害率 E₀ は Forager 0.122、Learner 32 行 0.098〜0.102、128 行 0.078 で、H1 の「先占者以外の採取率」の低下はこの水準からの差で読む。制裁なしの加害死の水準は preset × 128 行で約 13%。
- できない: H1〜H5 のいずれも（規則を 1 つも施行していない）。体力項は「飢えながら休む」を消さなかったので、制裁が「痛い」ことを報酬に返す経路は EXP-004 の後に残る設計問題。

## Phase 4 で検証したこと / できなかったこと（EXP-004、2026-10-18）

- `docs/research/experiments/EXP-004-first-occupant-norm.md`（仕様 89c48ef → 実行 → 結果 0b7a620。主対比 30 シード、帰無モデル 5 本、副次腕 2 本、同じ seed の対の差とブートストラップ CI、p 値なし）。
- **H1 の判定文は成立**: 条件 LE（Learner 128 行 90% + 台本の Enforcer 10%、先占規範 `Encroach { 32, HARM }` を布告）で学習者の侵害率（後半の窓）が同じ seed の LE0（規則なし）より 0.0669 低い（対の平均 −0.0669、95% CI [−0.0684, −0.0654]、d_z −15.4、0.080 → 0.013、30/30 シード）。制裁できない規則（N-nosanction）では下がらない（LE0 と物理が同一）。
- **ただし機構は「除去」で、規範の学習ではない**: 加害死 13% → 57%、Learner −30%、低下は布告直後の窓で既に現れて累積せず、制裁の痛みを報酬に入れた腕（W1、体力項 2）も規範情報を見ない腕（N-blind）も同じ値。学習者だけ + 規則（L1）でも侵害率は 0.074 → 0.047 に下がるが、それも同じ加害予算が Harm のアクチュエータの語彙（係争中の隣人を先に狙う、ADR-0014 D6）で係争者に集中して侵害者を殺す帰結（加害死 28%、Learner −34%）。
- **H1 の状態**: 「制裁と制裁を担う個体があれば学習者の侵害率が下がる条件がある」は支持（効果量は大きいがコストも大きい）。「所有権相当の規範が成立する = 学習者が従うことを学ぶ」は**未決**: 本実験の世界には学習者が従うことを学ぶ経路がない（体力項でも足りない = 信用割当の問題、EXP-004 の読み 3）。規範は布告で与えたもので、発明（立法の学習）は問うていない。
- 指標の教訓: 「時間的低下と持続」（H1 の主要指標の後半）は規則のない LE0 の方が満たす（学習の漂移）ので、規範の指標としては使えない。侵害率は共在の率で密度に依る（腕間で個体数が 30% 違う）。
- Phase 5 への引き渡し: 個体単位の追跡（除去と学習の分離）、信用割当（適格度トレース、`ENCROACHED_RECENTLY` の記憶ビット、γ）、Harm のアクチュエータの語彙・`standing_ticks`・制裁コスト・密度を H2 の格子の軸に、Enforcer の立法（`enforcer_motions`）で同じ指標を取る。H3 には改正を提案する立法者が要る（ADR-0014 D7）。
