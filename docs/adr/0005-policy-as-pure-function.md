# ADR-0005: 方策は enum ディスパッチの純関数。ベースラインとしてランダム方策を同梱

- 状態: 採用 (2026-10-17)

## 決定
- `PolicyKind { Forager, Random }` をエージェントに保持し、`decide(&Observation, &mut RngStream) -> Intent` で分岐。trait object は使わない（シリアライズ可能・決定論的・十分速い）。
- `Observation` は認知層に渡す情報の境界。今は自分の状態と視界内の食料のみ。
- `Random` は全行動から一様選択する帰無モデル。

## 理由
- Phase 3 で方策が学習器に置き換わっても、カーネル側の契約（Observation → Intent）は変わらない。
- 研究の観点では Forager は**設計者の知識を直接埋め込んだ方策**であり、それ自体が「創発」の証拠にはならない。比較対象（ランダム、および将来の学習方策）を初日から用意しておく。

## 再検討条件
方策の種類が増え、エージェントごとに異なるパラメータ／ゲノムを持つ段階（Phase 3/6）で、`PolicyKind` を `PolicyId` + 外部テーブルに分離する。
