# ADR-0003: カーネルは整数演算のみ・離散グリッド空間

- 状態: 採用 (2026-10-17)

## 決定
- エネルギーは `i64` のミリ単位、資源は `u32`、座標は `u16`。カーネル内で `f32/f64` を使わない。
- 空間は有界の 4 近傍グリッド、境界は壁。

## 理由
IEEE 754 自体は決定論的だが、FMA 融合・`libm` 実装差・SIMD 自動ベクトル化・並列リダクションの結合順でプラットフォーム間の差が出る。整数ならこの問題が原理的に生じない。

## 帰結・既知の課題
- Phase 3 でニューラル方策を入れると浮動小数点が必要になる。選択肢: (a) 固定小数点 NN、(b) 方策層のみ浮動小数点を許し「同一バイナリ・同一プラットフォーム内での再現」に保証を弱める、(c) 方策の出力を離散 `Intent` に落とすので、方策の非決定性をイベント台帳への記録で吸収する（再生は記録済み Intent から行う）。**(c) を第一候補**とし Phase 2 のイベント台帳設計で前提にする。
- 連続空間は Phase 1 の研究課題に不要。必要になれば固定小数点座標で導入。
